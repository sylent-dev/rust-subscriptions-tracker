# Tests by hand

The guides of the tests by hand: what only the window shows, or what needs the desktop of a system (the clipboard, the focus, the keys). Each guide is step by step, with a blank results table and a free test last; it is run again before every release (docs/releases.md). The results come back in the conversation or the pull request, never in the guide.
